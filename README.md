# RTOS 밑바닥부터 만들기

『나만의 RTOS 만들기(나빌로스)』를 따라 QEMU의 ARM RealView PB-A8(Cortex-A8, ARMv7-A) 환경에서 교육용 RTOS를 구현하는 프로젝트입니다.

운영체제가 없는 bare-metal 환경에서 시작해 다음 순서로 커널의 계층을 쌓습니다.

> 부팅 → 하드웨어 제어 → 태스크 → 스케줄러 → 컨텍스트 스위칭 → 동기화 및 IPC

## 구현 목표

- TCB 기반 태스크 생성 및 관리
- 선점형 우선순위 스케줄러
- 어셈블리 레벨 컨텍스트 스위칭
- 세마포어, 뮤텍스, 스핀락
- 이벤트 플래그와 메시지 큐
- UART, 타이머, 인터럽트 컨트롤러 제어

## 프로젝트 범위

이 프로젝트는 RTOS의 핵심 원리를 직접 구현하고 이해하기 위한 **교육용 최소 커널**입니다. 선점형 스케줄링, 컨텍스트 스위칭, 동기화 등 FreeRTOS 커널의 핵심 개념과 유사한 기능을 구현합니다.

다만 다음과 같은 제품용 기능은 포함하지 않습니다.

- MMU/MPU 기반 메모리 보호
- 소프트웨어 타이머와 틱리스 저전력 모드
- SPI, I2C, Ethernet, USB 등의 장치 드라이버
- 멀티코어 지원
- 네트워크 스택과 파일시스템
- 기능안전 인증과 결함 격리

학습 진행에 따라 구현 내용과 설명을 지속적으로 추가합니다.
